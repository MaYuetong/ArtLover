## ✅ 主清单 (Master Checklist)

### 阶段 0 · 准备（你来做）
- [ ] 填写 `INTAKE.md`（艺术家基本信息、定位、需求、参考网站）
- [ ] 把所有画作原图放进 `assets/raw/`（HEIC / JPG / PNG 都行，越高清越好）
- [ ] 放入肖像照、工作室照、简历、艺评/文章（如有）
- [ ] 明确：要中英双语吗？要不要在线询价 / 出售？域名有没有？

### 阶段 1 · 档案整理（我来做，依据 SKILL-archive.md）
- [ ] 格式归一：HEIC → JPG，统一命名 `Jiali-001 …`
- [ ] **去重**：全量两两比对 + 视觉确认，零重复（[[dedup-thoroughness]] 标准）
- [ ] 裁切 / 校色，生成 `Edited/` 母版集 + 网站用压缩版
- [ ] 建 `works.json`：每张画的元数据（标题/年份/媒材/尺寸/系列/状态…）

### 阶段 2 · 网站建设（我来做，依据 SKILL-design.md）
- [ ] 确定方向：画廊极简 / 暗黑大片 / 滚动叙事（见 SKILL-design 的三套方向）
- [ ] 视觉识别：配色、字体（变量字体 + kinetic 标题）、网格
- [ ] 首页 → 作品列表 → 作品详情（View Transitions 丝滑切换）
- [ ] 关于 / 艺术家自述 / 展览年表 / 联系
- [ ] 响应式（手机优先）+ 性能（响应式图片、懒加载）+ 无障碍
- [ ] 可选：PWA、双语切换、在线询价表单

### 阶段 3 · 打磨上线（我来做，依据 LOOP-refinement.md）
- [ ] 跑一轮 Refinement Loop（视觉 / 响应式 / 性能 / 无障碍 / 去重复检）
