# LOOP · 打磨循环 (Refinement Loop)

> 网站「建完」≠「做好」。建完之后跑这个循环，每一圈都让它更稳、更准、更精致。
> 学 `met-tour/` 的做法：每跑完一圈，升一个版本号并写进 `CORE.md`。

---

## 循环怎么转

```
   ┌─────────────────────────────────────────────┐
   │  ① 审视  →  ② 修  →  ③ 验  →  ④ 记录版本  ──┐ │
   └─────────────────────────────────────────────┘ │
                       ▲                            │
                       └──── 还有问题就再来一圈 ◄────┘
            没问题 → 退出，标记 vX.Y「可上线」
```

每一圈固定查 **5 个维度**，每个维度发现的问题先记成清单，再统一修，修完重验。

---

## 5 个检查维度

### ① 视觉 (Visual)
- [ ] 截图首页 / 作品列表 / 作品详情 / 关于，逐屏看
- [ ] 留白、对齐、网格是否一致；标题层级是否清楚
- [ ] 图片色彩贴近原作；无白闪、无变形、无拉伸
- [ ] 动效有没有「过」——可有可无的删掉

### ② 响应式 (Responsive)
- [ ] 手机 (375)、平板 (768)、桌面 (1440) 三档都过
- [ ] 手机上导航 / 筛选 / 详情切换可单手操作
- [ ] 无横向滚动、无文字被裁、无元素重叠

### ③ 性能 (Performance)
- [ ] Lighthouse 性能 ≥ 90；LCP < 2.5s
- [ ] 图片确实懒加载 + 响应式 `srcset` 生效
- [ ] 没有巨大未压缩图；CLS ≈ 0（无布局跳动）

### ④ 无障碍 + 兼容 (A11y)
- [ ] 对比度 ≥ 4.5:1；键盘能走完全流程；焦点可见
- [ ] 每张图 `alt` 正确；`prefers-reduced-motion` 下动画关闭
- [ ] View Transitions 在不支持的浏览器优雅降级

### ⑤ 内容 + 数据 (Content)
- [ ] **再跑一次去重复检**——零重复 ([[dedup-thoroughness]])
- [ ] `works.json` 无 `needs-confirm` 残留；无占位文字 / 死链
- [ ] 中英双语都齐（若双语）；标题/年份/媒材/尺寸准确
- [ ] 联系方式 / 社媒链接真实可点

## 版本记录（写进 CORE.md）

```
v1.0  首次上线
v1.1  修：手机端筛选溢出；详情图 srcset 生效
v1.2  加：系列页 scrollytelling；暗色模式
…
```

每圈结束在这里加一行：改了什么、为什么。和 `met-tour` 的 `fix(...) v2.9` 提交风格一致。

---

## 退出条件
5 个维度全绿、无 `needs-confirm`、Lighthouse 双指标达标 → 标 **vX.Y 可上线**，停止循环。
之后只在「加新作品」或「她提新需求」时再进循环。
